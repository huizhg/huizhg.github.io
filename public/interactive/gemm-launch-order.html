Grouped tile ordering, step by step

Grouping changes only which tile of C each pid gets. The math inside each program stays the same. Pick a GROUP_M, step through pids, and watch where each one lands.

Example: C has 7 tile rows × 6 tile columns = 42 programs. Assume the GPU runs a fixed number of programs at once, in pid order.

1. Cut C into bands

A band is GROUP_M tile rows tall. With GROUP_M = 3, rows 0–2 are band 0, rows 3–5 band 1, row 6 band 2.

2. Walk each band down, then right

Inside a band, pids fill a column top to bottom, then move one column right. The band finishes before the next one starts.

3. Two special cases

GROUP_M = 1 makes bands one row tall: a plain row walk. GROUP_M = 7, the full height of C, is a pure column walk, the order a 2-D grid with pid_m = tl.program_id(0) produces.
